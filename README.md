# 台灣菜價通

即時比較台灣蔬果、漁產、肉品與雞蛋價格的網頁。每次開啟都直接向[農業部農業資料開放平臺](https://data.moa.gov.tw/)抓取最新行情，不需要後端伺服器。

## 功能

- **搜尋**：支援俗名，例如「高麗菜」會對到「甘藍」、「空心菜」對到「蕹菜」。
- **價格趨勢**：7 天、1 個月、3 個月、6 個月、1 年，可疊加 7 日均線。
- **通路比價**：產地價、批發上價～下價區間、批發均價，畜產另有都市零售價。
- **地區比較**：台北、台中、台南、高雄、花蓮等縣市批發市場價格，附「由便宜到貴」排行。
- **最新行情看板**：最新交易日的蔬菜、水果批發均價與漲跌幅。
- **今日划算**：自動列出比近 30 天均價明顯便宜（或偏貴）的品項，並參考去年同期與交易量。
- **收藏與到價提醒**：收藏常買品項並設定提醒價，進站時上方會出現「今日提示」；設定 `alerts.json` 後，到價時會自動開 Issue（GitHub 寄信／App 推播），也可加 Telegram。
- **縣市地圖**：地區比較可切換地圖，依「與全台均價比」著色。
- **事件標註**：趨勢圖標出颱風警報期間與國定假日。
- **零售與賣場價**：通路比價加入台北公有零售市場月均價；「日用品」分類收錄 15 項民生必需品的量販店／超市價格（米、鮮乳、食用油、雞蛋等）。
- 元/公斤、元/台斤一鍵切換；手機可「加入主畫面」當 App 使用。

## 資料來源

| 類別 | 資料集 | 更新頻率 |
|---|---|---|
| 蔬菜、水果批發 | 農產品交易行情 | 每日 |
| 蔬果產地價 | 農產品產地價格 | 每日 |
| 漁產批發 | 漁產品交易行情 | 每日 |
| 毛豬 | 毛豬交易行情 | 每日 |
| 雞、鴨、鵝、蛋 | 家禽交易行情 | 每日 |
| 畜產零售 | 畜產都市零售價格 | 每月（落後數月） |
| 零售（台北） | 臺北市市場處 公有零售市場行情（data.taipei） | 每月（約每年公布一次） |
| 量販店／超市 | 國發會物價資訊看板 15 項民生必需品賣場價格 | 每月 |

全聯、家樂福等業者沒有公開的價格資料介面，因此不抓取各家網站。

## 運作方式

- `.github/workflows/update.yml` 每天台灣時間 8:10、14:10、20:10 執行：
  1. `scripts/update.mjs` 向農業部 API 抓新資料，原始資料存在 `store/`（第一次會回補約 400 天，可能要跑 2–3 次才補完）。
  2. `scripts/build.mjs` 把資料整理成網頁讀取的小檔案，輸出到 `site/`。
  3. `scripts/alerts.mjs` 依 `alerts.json` 檢查到價提醒。
  4. 部署到 GitHub Pages。
- 想立刻更新：到 Actions → 「更新菜價資料並部署」→ Run workflow。
- 颱風警報期間記錄在 `events.json`，可自行增修。
- 國發會的賣場價格網站不接受 GitHub 伺服器的連線，所以這部分無法自動更新。每月想更新時，在台灣的電腦上執行 `ONLY=ndc node scripts/update.mjs`，再 commit 並 push `store/ndc` 即可（需要 Node 20 以上）。

## 到價推播

1. 在網頁「收藏」頁設定提醒價，按「複製設定」。
2. 貼到 `alerts.json` 並 commit。到價時會在本 repo 開 Issue。
3. （選用）Telegram：在 repo Settings → Secrets and variables → Actions 新增 `TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`。

## 本機使用

直接用瀏覽器開啟 `index.html` 也能用，此時會即時向農業部查詢（較慢，部分功能如「今日划算」需要部署版的每日資料）。
